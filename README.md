- **지원자 보관용 사본 로컬 즉시 다운로드**:

## ⚡ 성능 및 리소스 최적화 & 보안 고도화 내역 (Optimization Highlights)

1. **렌더 블로킹(Render-Blocking) 스크립트 제거**:
   - `index.html` 상단 `<head>`에 중복 삽입되어 브라우저 파싱 및 렌더링을 차단하던 외부 라이브러리(`html2pdf.bundle.min.js`)를 제거하여 First Contentful Paint(FCP) 로딩 속도를 대폭 개선했습니다. (문서 하단 정품 라이브러리 단일 로드 체계)
2. **지원자 배포 파일 단일화 및 불필요한 자동 다운로드 방지**:
   - 지원서 접수 완료 시 지원자 PC로 자동 다운로드되던 중복 개발 백업 파일(`.json`)을 제거하고, 오직 **공식 A4 2-Page 규격 지원서 PDF만 단일 발급**하도록 정돈하여 사용자 경험을 깔끔하게 완성했습니다.
3. **미사용 에셋 및 폴더 완전 정리 (저장소 경량화)**:
   - 과거 테스트용으로 남아있던 대용량 중복 원본 로고(`image/AIONE 로고.png`, 약 1.04MB) 및 불필요한 디렉토리를 완전히 제거하여 `assets/logo.png` 단일 에셋으로 통합 및 경량화했습니다.
4. **미사용 데드 코드(Dead Code) 제거 및 스크립트/스타일 캐시 버스터 갱신**:
   - 실무에서 쓰이지 않던 구버전 URL 압축 뷰어 생성 유틸리티 함수(`createApplicantViewerLink`)를 정리하고, 최신 스크립트 및 스타일시트 캐시 버스터(`?v=20261030_06`)를 적용하여 방문자가 브라우저 캐시 없이 항상 최신 코드를 로드하도록 보장했습니다.
5. **다크 모드 상속 차단 및 공식 온라인 열람기 이중 고대비 가독성 강화**:
   - 관리자 온라인 열람기 모달 내부의 DOM 스타일에 고특이도 스코프 CSS 규칙을 적용함과 동시에, 모달 오픈 시 복제된 가상 DOM 노드에 직접 고대비 인라인 색상(`#0f172a`, `opacity: 1`)을 주입하여 구형 브라우저 캐시 환경에서도 지원자 기재 항목(지원구분, 연락처, 병역, 기술스택, 자기소개 등)이 100% 선명하게 표시됩니다.
6. **2계층 권한(총괄 관리자 vs 일반 랩원) 보안 시스템 구축**:
   - 로그인 비밀번호에 따라 **총괄 관리자(LAB ADMIN)**와 **일반 랩원(LAB MEMBER)**으로 자동 분기되는 2-Tier Role-Based Access Control(RBAC) 시스템을 도입했습니다.
   - 일반 랩원에게는 지원서 목록 조회, 실시간 검색, 공식 2-Page PDF 다운로드, 온라인 열람기, CSV 내보내기만 허용하고, **지원서 삭제(개별/일괄) 및 비밀번호/연동 설정 제어를 화면 UI 및 백엔드 API 양단에서 원천 차단**하여 안전한 다자간 연구실 운영 환경을 확립했습니다.
7. **GitHub 공개 대비 평문 비밀번호 원천 제거 및 SHA-256 단방향 보안 해싱**:
   - 오픈소스 및 GitHub 공개 배포 환경을 고려하여 모든 소스코드, 주석, 안내 문서에서 평문 비밀번호를 100% 제거하고 수학적으로 복호화가 불가능한 **SHA-256 단방향 암호화 해시 체계**로 강화하여 보안 무결성을 확보했습니다.
8. **구글 드라이브 폴더 자동 탐색 및 PDF 바이너리 무결성 파이프라인**:
