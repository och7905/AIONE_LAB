### 1. 공식 입실 지원서 양식 PDF 자동 생성 (Zero-Clipping 2-Page Direct Engine)
- 지원서 접수 버튼 클릭 시 `html2canvas` 및 `jsPDF` 엔진을 통해 지원자의 모든 응답이 기재된 **공식 대학교 연구실 입실 지원서 양식**이 실시간 컴파일됩니다.
- **2페이지 독립 캡처 및 결합 아키텍처 (Zero-Clipping Guarantee)**:
  - 기존의 단일 캔버스 자동 분할 시 발생하던 뷰포트 크기 간섭, 우측 짤림, 여백 불균형 버그를 원천 차단하기 위해 **1페이지([`#pdf-page-1`](file:///c:/Users/오창현/Desktop/AIONE LAB/index.html))와 2페이지([`#pdf-page-2`](file:///c:/Users/오창현/Desktop/AIONE LAB/index.html))를 완전 분리**하여 개별 렌더링합니다.
  - A4 96 DPI 정규 픽셀 규격(`794px × 1123px`)으로 고해상도 2배수(`scale: 2`, `1588px × 2246px`) 개별 캡처 후, `jsPDF`를 통해 표준 A4(`210mm × 297mm`) 규격에 1:1 무손실로 정확하게 2페이지를 순차 결합합니다.
  - **뷰포트/스크롤 정규화 & DOM 격리 (`onclone`) 기술 적용**:
    - 스크롤 위치 간섭 방지를 위해 캡처 시작 시 뷰포트 좌표를 일시적으로 `(0, 0)`으로 정규화한 뒤 캡처 후 원위치로 자동 복원합니다.
    - 모바일 기기(너비 360~412px) 및 협소 브라우저 환경에서 발생하던 우측 잘림 방지를 위해, 캡처 중 `body` 최소 너비를 `794px`로 확보하고 가상 DOM(`onclone`) 내부에서 `overflow: visible` 및 절대 좌표 배치를 강제합니다.
    - 테이블과 서술 상자에 `table-layout: fixed; box-sizing: border-box; word-break: break-word;`를 적용하여 긴 텍스트 입력 시에도 경계선 돌출이나 글자 잘림이 0%로 완벽 방지됩니다.
  - `doc.save()` 및 가상 Blob 앵커(`URL.createObjectURL`) 이중 다운로드 방식을 채택하여 데스크톱 및 모바일(iOS Safari, 안드로이드 Chrome) 상관없이 지원자 컴퓨터(다운로드 폴더)에 **`AIONE_2026_지원서_{학번}_{이름}.pdf`** 파일이 100% 자동 저장됩니다.

## 🚀 실행 및 배포 방법 (How to Run & Deploy)

### 1. 로컬 환경에서 원클릭 실행
- 별도의 Node.js나 Python 설치 없이, 폴더 내 **`start-server.bat`** 파일을 더블 클릭하면 PowerShell 로컬 서버가 구동되며 기본 브라우저(`http://localhost:8080/`)가 자동으로 열립니다.

### 2. GitHub Pages 배포 (추천)
1. GitHub 저장소(Repository)에 프로젝트 파일 전체를 푸시합니다.
2. 저장소의 `Settings` > `Pages` 메뉴로 이동합니다.
3. `Branch`를 `main` 또는 `master`의 `/(root)`로 지정 후 `Save`를 클릭합니다.
4. 약 1분 후 `https://<github-id>.github.io/<repo-name>/` 주소로 전 세계 어디서나 접근 가능한 고속 정적 웹사이트로 배포됩니다.

### 3. Vercel 또는 Netlify 배포
- 저장소를 연동하거나 폴더를 드래그 앤 드롭하는 것만으로 빌드 설정 없이 즉시 글로벌 CDN에 배포됩니다.

## ⚙️ Google Apps Script를 통한 실제 PDF 첨부 메일 자동화 설정법 (무료)

Formspree 무료 플랜 대신 **네이버 메일에 실제 `.pdf` 파일이 직접 첨부되어 오도록** 만들고 싶으신 경우 아래 3단계를 진행하시면 됩니다:

1. [Google Apps Script (script.google.com)](https://script.google.com/) 접속 후 **새 프로젝트** 생성
2. 아래 코드를 붙여넣고 저장:
```javascript
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var pdfBlob = Utilities.newBlob(
    Utilities.base64Decode(data.pdfBase64), 
    'application/pdf', 
    data.filename || ('AIONE_2026_지원서_' + data.student_id + '_' + data.name + '.pdf')
  );

  MailApp.sendEmail({
    to: 'och7905@naver.com',
    subject: '[AIONE LAB 신규 지원서 PDF] ' + data.name + ' (' + data.student_id + ' / ' + data.grade + ')',
    body: 'AIONE LAB 2026학년도 신규 연구원 지원서 PDF가 첨부되었습니다.\n\n' +
          '지원자: ' + data.name + ' (' + data.student_id + ' / ' + data.grade + ')\n' +
          '연락처: ' + data.phone + '\n' +
          '제출일시: ' + new Date().toLocaleString('ko-KR') + '\n\n' +
          '(첨부된 PDF 파일을 확인해 주세요)',
    attachments: [pdfBlob]
  });

  return ContentService.createTextOutput(JSON.stringify({ status: 'success' })).setMimeType(ContentService.MimeType.JSON);
}
```
3. 우측 상단 **[배포] > [새 배포]** 클릭:
   - 유형: **웹 앱(Web App)**
   - 액세스 권한: **모든 사용자(Anyone)** 선택 후 배포
4. 발급된 **웹 앱 URL**을 복사하여 [`js/form.js`](file:///c:/Users/오창현/Desktop/AIONE%20LAB/js/form.js) 상단의 `GOOGLE_APPS_SCRIPT_URL`에 넣어주시면 설정이 완료됩니다.
